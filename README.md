# PepFGLD

**Flexibility-Aware Geometric Latent Diffusion for Full-Atom Peptide Design**

We are pleased to announce that **PepFGLD** has been accepted by **ICML 2026**.

PepFGLD is a flexibility-aware geometric latent diffusion framework for full-atom peptide design. This repository will provide the official implementation, experimental configurations, and data resources associated with our paper.

## News

- **[2026]** PepFGLD has been accepted by **ICML 2026**.
- The code and experimental data are currently being packaged and uploaded to cloud storage. Once the upload is complete, we will share the download links here.

## Code and Data

The official code, pretrained models, processed datasets, and experimental results will be released soon.
